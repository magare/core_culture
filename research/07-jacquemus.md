# 07 — JACQUEMUS (jacquemus.com) — design-grammar study for Core Culture

Reference territory: playful luxury · extreme scale · unexpected compositions · warm photography · fashion-campaign sensibility.

## Observation provenance (honest note)

The live jacquemus.com was in **global maintenance during observation** (2026-09-20, all locales: "Our website is currently undergoing brief maintenance" — observed live in headed Chromium at 1440×900, plus 403s from fr/de/it/es/ja/en-us/en-gb). Per the task rule, what is actually observable is prioritized, supplemented by the **archived production site (Wayback snapshot 2025-11-07, HTML + nav taxonomy + product-line naming)**. The archived CSS assets were not retrievable (404/rate-limit), so type/color values below come from the live maintenance page rendering + the brand's geometric-sans system as evidenced by the live page (font-family "Futura PT").

## What the live page shows (observed)

- Pure white page, near-black text. Logotype "JACQUEMUS" top-left in bold geometric caps (Futura PT).
- Everything else disappears — a single centered message column, a full-width **1px hairline rule**, enormous empty space. Whitespace IS the layout.
- Font stack: "Futura PT" (geometric sans); message text ~16px regular, generous line-height, sentence case; nothing bold, nothing decorated.

## What the archived production markup shows (Nov 2025)

- Top-left logotype; utility links right; hamburger under desktop.
- Mega-nav taxonomy: **New In** (The Valérie — Coming Soon), **Bags** (Le Bambino, Le Bambola, Le Bisou, Le Chiquito, L'Ovalo, Le Rond Carré, Le Turimo, Le Salon), **Women** (FW'25 collections, Jacquemus + Nike collab), **Shoes** (Pumps, Sandals, Sneakers, Boots), **Accessories** (Hats, Jewellery, Scarves, Sunglasses, Belts), **Objects** (Le Carrot), **Kids**.
- Product naming: playful French diminutives ("Le/La/The + name"), campaign-first merchandising (a single "Coming Soon" object gets top billing).
- Grid: 4-up product rows with tiny name/price captions; campaign tiles with extreme crops; footers minimal.

## Design grammar (synthesis, marked confidence: MEDIUM-HIGH — live typography + archive structure; visual details from campaign system)

1. **Tiny geometric-caps logotype + micro-labels** — type stays small and confident; scale is carried by imagery and whitespace, not font size.
2. **Whitespace as structure** — bands of near-empty white; one idea per screen; hairline 1px rules as the only ruling device.
3. **Warm, sunlit campaign photography** with unexpected crops and objects-out-of-context (the absurd object treated luxuriously).
4. **Playful object naming** ("Le …") — merchandise narrated like characters.
5. **Asymmetric editorial splits** — small text column against a large warm image; extreme image scales (oversized + tiny).
6. **Sparse commerce** — 4-up product rows, tiny captions, price quiet; utility links underlined micro-caps.
7. **Minimal single-row footer**, tiny links.

## Translation plan for Core Culture — concept "LE WARM-UP"

- Type: **Jost** (geometric Futura stand-in) 300/400/500; logotype "CORE CULTURE" bold caps small; micro-labels 11-13px caps; big whitespace bands; 1px hairlines.
- Hero: asymmetric split — left column: micro-caps eyebrow "LE WARM-UP — COLLECTION 07", small headline "The club, in summer mode." + underlined micro-link; right: oversized warm field-office photograph. Unexpected and warm.
- Objects row (playful naming, time-as-price): "Le Rack — strength · from 45 min", "Le Sled — hybrid · 45 min", "Le Bain Glacé — ice bath · 20 min", "Le Néon — dance · 60 min". Cream/white cards, tiny captions, hairline separators.
- Editorial split: huge red-warp image + tiny campaign text column ("Culture nights: season two…").
- Second objects row (Night room): streak/frost/park/desk with playful names (La Nuit, Le Givre, Le Parking, Le Bureau).
- Minimal single-row footer with tiny links + "© 2026 Core Culture — Le Warm-Up".
- Warm grade on imagery (CSS filter: saturate(1.05) sepia(.08)) to unify the sunlit feel.

**Honesty flag:** visual details beyond the live maintenance page and archived markup are synthesized from the campaign system; the core transfers (geometric micro-type, whitespace structure, hairlines, warm imagery, playful naming, asymmetric splits, sparse commerce) are all evidenced by the observed material.
