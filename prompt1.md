# SUPPLEMENT — 3D / DIMENSIONAL ART DIRECTION

This instruction supplements the main Core Culture 20-page brief.

The 3D requirement is NON-NEGOTIABLE.

However, understand this clearly:

# 3D ≠ THREE.JS

Three.js is ONE possible technique.

The actual objective is:

# DEPTH + PHYSICALITY + SPATIAL EXPERIENCE

Every Core Culture landing page must contain a meaningful dimensional idea, but the technique and visual result must differ substantially between concepts.

# 3. DO NOT COPY REFERENCES

References establish the QUALITY BAR.

They do NOT provide templates.

Never reproduce:

* exact layouts
* exact objects
* recognizable animations

# 4. 3D TECHNIQUE LIBRARY

Across the 20 landing pages, deliberately explore different dimensional technologies.

Possible approaches:

* Three.js
* WebGL
* React Three Fiber if already appropriate for the project
* GLSL shaders
* particles
* procedural geometry
* custom materials
* lighting
* environment mapping
* distortion

### PRE-RENDERED 3D

3D does NOT need to be generated in the browser.

Use:

* rendered sculptures
* chrome objects
* metallic typography
* abstract anatomical forms
* impossible gym equipment
* liquid-metal objects
* glass objects
* cloth simulations
* rendered environments
* image sequences
* transparent rendered assets

These can often create stronger art direction with significantly better performance.

---

### CSS 3D

Explore:

* perspective
* perspective-origin
* translateZ
* rotateX
* rotateY
* transform-style: preserve-3d
* perspective card stacks
* dimensional typography
* spatial galleries
* depth-based navigation
* layered sections

CSS 3D can be extremely effective when art-directed properly.

Do not underestimate it.

---

### 2.5D PHOTOGRAPHY

Separate photography into spatial planes:

FOREGROUND

MIDGROUND

BACKGROUND

Create depth using:

* subject cutouts
* masks
* different scroll speeds
* perspective
* scale
* blur
* lighting
* overlap
* shadows
* depth-based motion

An athlete can exist BETWEEN typography layers rather than merely underneath text.

---

### TYPOGRAPHIC 3D

Typography itself can become the dimensional element.

Explore:

* extrusion
* repeated depth layers
* perspective
* warped text
* cylindrical typography
* tunnel typography
* stacked typography
* rotating letterforms
* letters existing on different Z-planes
* giant words acting as architecture
* text wrapping around invisible geometry
* text disappearing behind bodies
* typography functioning as physical structure

Do not always place text on top of 3D.

Sometimes:

# THE TEXT IS THE 3D.

---

### VIDEO + DEPTH

Use combinations such as:

video
+
masks
+
DOM
+
CSS perspective
+
scroll
+
typography

to create perceived three-dimensionality.

This can produce spectacular results without expensive WebGL.

---

### LIGHT AS 3D

Depth can come from illumination.

Imagine a nearly black screen.

An object exists in darkness.

Cursor movement changes a virtual light source.

The visitor does not rotate the object.

They REVEAL it.

Possible objects:

* athlete
* barbell
* weight plate
* sculpture
* CORE CULTURE typography
* abstract body
* training equipment

This is a completely different interaction model from rotating a model.

---

### GLASS / REFRACTION

Use:

* translucent surfaces
* refraction
* distortion
* frosted layers
* chromatic aberration
* reflective material
* lens-like UI
* magnification
* liquid surfaces

This may work particularly well for:

RECOVERY

rather than strength training.

---

### DEPTH THROUGH SCROLL

Scrolling can move the visitor THROUGH the composition instead of simply moving content upward.

Examples:

entering typography

moving between photographs

passing through a tunnel

approaching an athlete

moving through gym zones

crossing spatial layers

objects approaching and disappearing behind the camera

Use sparingly and intentionally.

# 8. 3D MUST INTERACT WITH THE PAGE

Avoid:

3D canvas at top
+
normal website underneath.

The dimensional concept should influence the broader experience.

For example:

A heavy sculpture could affect typography.

An athlete could occlude navigation.

A glass object could refract section content.

A perspective tunnel could become navigation.

A moving light could reveal both objects and copy.

A spatial grid could organize amenities.

The 3D idea and interface should feel connected.

---

# 9. 3D + TYPOGRAPHY INTERACTION

Whenever appropriate, allow dimensional objects to interact with typography.

Examples:

text behind object

text in front of object

object passing through letters

type casting shadows

photography crossing text planes

letters becoming objects

objects breaking grids

text revealed through material

Avoid the predictable composition:

LEFT = text

RIGHT = 3D model

unless one concept specifically justifies it.

# 13. PERFORMANCE RULE

Never choose technical complexity merely to impress.

If:

CSS 3D

can produce the desired result better than:

Three.js

use CSS.

If:

pre-rendered animation

works better than real-time WebGL:

use pre-rendered animation.

If:

layered photography

creates stronger depth than either:

use layered photography.

Choose the simplest technology capable of producing the strongest visual experience.

---

# 14. MOBILE 3D

Every dimensional experience needs an intentional mobile interpretation.

Do not assume desktop mouse interaction exists.

Replace:

cursor tracking

with:

touch movement

scroll position

device-independent animation

or a simplified composition.

Reduce expensive rendering where necessary.

The mobile experience should preserve the IDEA even if implementation changes.

---

# 15. 3D QUALITY CHECK

Before approving every page, ask:

### Is there meaningful depth?

If no → FAIL.

### Is the dimensional concept visible and important?

If no → FAIL.

### Does it relate to Core Culture?

If no → FAIL.

### Is it different from the dimensional technique used by previous pages?

If no → REDESIGN.

### Does it work with typography rather than merely sitting beside it?

If no → IMPROVE.

### Does it work on mobile?

If no → FIX.

### Does it maintain good performance?

If no → OPTIMIZE.

### Does it look intentional rather than gimmicky?

If no → REDESIGN.
