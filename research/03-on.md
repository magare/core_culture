# 03 — ON RUNNING (on.com, geo-served en-in) — design-grammar study for Core Culture

Reference territory: technical performance mixed with fashion/editorial presentation · clean compositions · product storytelling.
Confidence: FULL (live-browser observation, headed Chromium 1440×900, 2026-09-20). Region dialog overlays some captures; every component below was read behind/around it. Screenshots `/tmp/on-shots/`, computed facts `/tmp/on-report.json`.

## Snapshot

Swiss-engineering friendliness: an all-white page where everything is sentence case, bold but never shouty. Type is one humanist-grotesk family ("On" / Diatype) in two sizes — huge bold section heads (~50px/700, tight tracking) and small confident labels. Light-gray product fields, rounded pill buttons (white on image, black on white — always with optional → arrow), carousels driven by thin arrow glyphs + a hairline progress line. Color arrives only inside photography and product. The signature is a giant interactive index of sports — huge bold sentence-case lines that swap an image.

## Visual identity (from live DOM + captures)

- **BG** white; product/panel fields `#f0-f2` light gray; text `#111` heads / `#333` body; black feature cards `#000` with white bold text. No chrome accent color.
- **Type**: single grotesk ("On", "On Diatype", mono variants). H2 "Shop" **49.6px / 54.5 / 700 / −0.5px / sentence case**. Hero "Dream On, Soccer" ~56px/700 white sentence case. Sports-index lines ~44-56px/700. Body 18.8px/28 #333. Card captions ~18-20px/700 white. Product name 16/700 + gray descriptor 14-16/400.
- **Buttons**: fully-rounded pills. White-on-image ("Find out more", ~40px tall, 14px/700 black text); black-on-white ("Read more →" with arrow glyph); small "Cancel ✕" outline pill in dialog.
- **Decoration**: hairline progress lines under carousels; heart icons on product tiles; rounded-corner dialogs (~12px); tiles square-ish with flat gray fields.

## Composition

- Hero full-bleed ~86vh, transparent header (white mark left, centered nav Shop/Sports/Explore, icons right), text **bottom-left**: headline + white pill.
- "Shop": giant head at 48px margin → 3-up tall model tiles, small bold white caption bottom-left.
- **Sports index**: left column of giant bold sentence-case lines (Running / Road running / Marathon / Trail running / Lifestyle / Hiking / Tennis / Training), image right — interactive swap.
- Product carousels ("New arrivals"): 4 visible + peek, tiles on light gray, name bold + gray descriptor line, controls = ← → arrow glyphs + hairline progress line (no circles — a key differentiator from Nike).
- "Stories that move": 4-up editorial cards with bold white bottom-left captions, mixed with **pure black cards carrying only a bold white sentence** ("Powered by Swiss engineering." / "We believe movement happens…").
- Mission: horizontal collage strip (offset image cards + black sentence cards), then "Our mission" head + 32px statement ("Ignite the human spirit through movement") + black pill "Read more →".
- Footer: light — newsletter ("Stay in the loop…") with gray input, link columns, region row, legal + social icons.
- Margins 48px; 3-4 tiles per row max; one idea per band.

## Motion

- Carousels: smooth scroll, arrows + progress line; interactive index swaps image (crossfade); subtle image hovers; region dialog slide. No scroll-jacking; quiet, precise, engineered.

## Storytelling

Product storytelling with a mission close: campaign hero → shop the floor → find your sport (index) → product stories (carousels) → culture/stories → mission statement → newsletter. Voice: deadpan engineer-optimism, sentence case: "Ignite the human spirit through movement."

## SIGNATURE CHARACTERISTICS

1. **Sentence-case bold everything** — huge tight-tracked heads and giant index lines, never uppercase, always friendly-confident.
2. **Pill buttons with arrows** — white-on-image and black-on-white, "Read more →".
3. **Light-gray product fields** with name + deadpan gray descriptor under every object.
4. **Arrow-glyph carousel controls + hairline progress line** (no circles).
5. **The giant interactive index** of activities swapping one image.
6. **Black sentence cards interleaved with imagery** — pure text posters inside editorial rows.
7. **Mission close** — image collage + quiet statement + arrow pill; light footer with newsletter.

## Translation opportunities for Core Culture

- Inter for "On"-style grotesk; heads 36–52px/700 sentence case; captions bold white bottom-left.
- "The floor" 3-up (Weights / The studio / Engine room) from machine / dancer / sled columns.
- **Discipline index**: Strength / Conditioning / Dance / Recovery / Community / Arrival as giant bold lines swapping images (keyboard operable).
- Class carousel with deadpan descriptors ("For engines, and the days after leg day."), arrow glyphs + progress line.
- Story row alternating image cards and black sentence cards ("Powered by industrial air.", "We believe recovery is training.").
- Mission band: field-desk collage + "Training is only part of the culture." + "Read more →".
- Light footer with newsletter + region-style line ("The Foundry District · Open 05:00–23:00").
